# Server Health & Event Log Checker

Windows環境におけるサーバーの死活監視と、Windowsイベントログ（System）からのエラー・警告抽出を自動化するPowerShellスクリプトです。

## 🛠 概要 (Overview)
中小企業や社内インフラの保守・運用において、「毎日の死活確認」や「トラブルの予兆検知（イベントログ確認）」を効率化するために作成しました。
リモートサーバーやローカル環境に対して手軽に実行でき、結果をコンソールおよびログファイルに分かりやすく出力します。

## ✨ 主な機能 (Features)
- **Ping死活監視:** 指定したサーバーのリスト（IP/ホスト名）に対して疎通確認を実施。
- **イベントログ自動抽出:** 過去24時間以内のシステムログから、エラー(Level 1)および警告(Level 2)を自動でピックアップ。
- **安全なエラーハンドリング:** 疎通がないサーバーに対する無駄な処理をスキップし、タイムアウトや権限エラーにも対応。
